# Control by Ouroboros
AI TAKE THE WHEEL. Control by Ouroboros lets your AI assistant see and operate your PC through MCP, with consent and hard safety blocks.

**Closed source.** This repository holds documentation and manifests only. Get the Windows early release from https://ouroborosapps.com/control.

## Pricing
$7.50/month or $75/year per PC (15% off for 10+ PCs), 7-day free trial, purchased at https://ouroborosapps.com/control. Terms: https://ouroborosapps.com/control-terms

## Install
1. Download the Windows early release (12.0.29) from https://ouroborosapps.com/control.
2. Activate with your license key.
3. Add Control to your MCP client (see https://ouroborosapps.com/control).

## Safety
Asks before taking control; stop hotkey returns it instantly. Payment screens, card data, password/sign-in fields and destructive commands are blocked or held; deletes require confirmation.
