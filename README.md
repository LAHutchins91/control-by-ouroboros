# Control by Ouroboros
AI TAKE THE WHEEL. Control by Ouroboros lets your AI assistant see and operate your PC through MCP, with consent and hard safety blocks.

**Closed source.** This repository holds documentation and manifests only. Download the installer from https://ouroborosapps.com/downloads/control/Control-Setup.exe.

## Pricing
$20/month or $200/year per PC, 7-day free trial, purchased at https://ouroborosapps.com/control. Terms: https://ouroborosapps.com/control-terms

## Install
1. Download and run the installer from https://ouroborosapps.com/downloads/control/Control-Setup.exe (available once the compiled early-release build is published).
2. Activate with your license key.
3. Add Control to your MCP client (see https://ouroborosapps.com/control).

## Safety
Asks before taking control; stop hotkey returns it instantly. Payment screens, card data, password/sign-in fields and destructive commands are blocked or held; deletes require confirmation.
