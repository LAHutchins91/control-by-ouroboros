# Control by Ouroboros
AI TAKE THE WHEEL. Control by Ouroboros lets your AI assistant see and operate your PC through MCP, with consent and hard safety blocks.

**Closed source.** This repository holds documentation and manifests only. Get the Windows early release from https://ouroborosapps.com/control.

## Install (Windows 10/11)
1. Download the one-click installer, [Control-Setup.exe](https://ouroborosapps.com/downloads/control/Control-Setup.exe) (version 12.3.5). SHA-256: `4047587f5ed73c074d1dea4d9ddcae445a365ba7b1eac15d883c555c6cdc150d`.
2. Run it, then open Control. You don't need Python or any config edits.
3. In the first-run wizard, start the 7-day trial or paste your `OBR1` license key. Control then connects itself to Claude Desktop and Cursor, backing up their settings first.
4. Restart Claude Desktop or Cursor and ask your AI to do something on your PC.

To uninstall, go to Windows Settings → Apps → Control by Ouroboros → Uninstall. This removes the app, its shortcuts and its Claude/Cursor entries.

Full user manual: https://ouroborosapps.com/docs/control ([PDF](https://ouroborosapps.com/downloads/control/Control-User-Manual-v12.3.5.pdf))

## Safety
Asks before taking control, with no session time limit. Grab the mouse and control comes straight back to you. Payment screens, card data, password/sign-in fields and destructive commands are blocked or held; deletes require confirmation.
